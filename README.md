# Lunar Odyssey

An original lunar outpost survival game for NASA Space Apps 2026 (project JAMT: Junior Astronaut Mission Trainer).

Run the base at Shackleton Crater for 30 days: manage oxygen, water, food, power and radiation shielding, drive the rover, mine polar ice, and get through solar storms and dark spells. Story mode has 3 chapters with cutscenes, a Chapter 1 training checklist, several endings and a certificate.

## Play

The game is one file: `mockups/index.html`. Serve the `mockups` folder with any static server, for example:

    npx serve mockups

and open the printed address. The 3D view loads Three.js from a CDN, so you need internet.

## Notes

`mockups/REALISM_NOTES.md` has the science behind the game, the balance test results and the story chapters.
